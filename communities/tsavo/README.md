# TSAVO Royal Suburbs instance

This is the first concrete Zalagren community instantiation for the TSAVO demonstrator.

It separates researched real-world facts, canonical Zalagren entities, evidence, and information that still requires authoritative verification.

Canonical hierarchy:

**Place/Site → Phase → Building → Unit**

The instance does not invent residents, buildings, units, permissions, credentials, providers, or access rights.

Research references:
- https://tsavo.ke/property/royal-suburbs/
- https://tsavo.ke/tsavo-lifestyle/
- https://www.nema.go.ke/

“Tsavo” here refers to the TSAVO real-estate/community demonstrator in Roysambu, Nairobi, not Tsavo National Park.
