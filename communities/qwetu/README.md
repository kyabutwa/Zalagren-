# Qwetu

Qwetu is represented in Zalagren as a researched community/property instantiation, not as a copied property-management system.

## Current instantiation

**Qwetu Ruaraka**, Nairobi, Kenya.

Evidence is sourced from Qwetu and Acorn/ASA I-REIT public materials. The current instance records only externally supported facts.

## Zalagren boundary

This instantiation does not fabricate residents, staff, rooms, Units, relationships, permissions, visitor credentials, utility accounts or operational events.

Qwetu's existing systems and visitor-management controls are external systems. Zalagren does not assume integration, authority or data access without an explicit integration and authorization contract.
