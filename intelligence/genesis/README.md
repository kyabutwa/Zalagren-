# GENESIS

GENESIS is Zalagren's governed intelligence engine.

Canonical loop:

Observe → Understand → Contextualize → Detect → Reason → Propose → Authorize → Execute → Measure → Learn

GENESIS consumes governed observations, knowledge and evidence. It may produce proposals and,
when an authorized execution path exists, participate in execution.

GENESIS is never an authority source. It cannot create its own authorization, silently elevate
privileges, or treat a proposal as an executed action.

Execution must remain connected to the Core Action/Authorization boundary.
