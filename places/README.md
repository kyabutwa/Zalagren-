# Places

Places are first-class physical/contextual entities in Zalagren.

Canonical hierarchy supported by this domain:

Place/Site → Phase → Building → Unit

A Community may contain or govern places, but a place does not become a participant role.
A Unit is the canonical entity for an individual dwelling or other assignable space; “Apartment” is not used as the entity name.

Access, occupancy, ownership, management, visitation and service relationships are represented separately through Relationship, Context, Capability and Authorization.

Closing a place, building, phase or unit preserves identity and history.
