# Zalagren iOS

Native SwiftUI interface for the single Zalagren app.

Target: Xcode 27 / iOS 27 design direction, with iOS 17+ deployment compatibility. iOS 26+ receives the current Apple Liquid Glass system treatment through SwiftUI availability checks; older supported systems use semantic materials.

The interface is adaptive rather than pixel-hard-coded. Safe areas handle notches, Dynamic Island and the home indicator. Dynamic Type and VoiceOver labels are used for critical controls.

The iOS client never grants authorization. CONSTANTYNA and GENESIS remain governed intelligence layers; protected actions must be authorized by Zalagren Core.
